05학습은 어떻게 하나

벌점을 줄이는 방향으로, 조금씩

순전파

현재 다이얼로 다음 토큰 확률 계산

손실

정답 확률이 낮을수록 큰 벌점
(교차 엔트로피: −log p)

역전파

각 다이얼의 책임을 출력→입력으로 거슬러 계산 (Rumelhart·Hinton·Williams, 1986)

경사하강법

벌점이 줄어드는 방향으로 모든 다이얼을 아주 조금씩

이걸 수조 개 토큰에 대해 반복

비유 · 안개 낀 산을 눈 가리고 내려가기

경사를 계산 = 역전파 · 한 걸음 = 경사하강법

06트랜스포머와 어텐션

문맥은 어텐션이 읽는다

"나는 이런 정보를 갖고 있어"

  • Query·Key가 잘 맞을수록 그 Value를 더 가져온다

  • 멀티헤드: 여러 갈래 동시 수행 (원 논문 8개)

비유 · 회의실에서 아는 사람에게 귀 기울이기

"주목"은 의도적 집중이 아니라 벡터 유사도 점수로 가중 평균을 내는 연산

09학습과 추론

공장 짓기 vs 공장 돌리기

Training · 학습

다이얼을 맞추는 과정

  • 순전파 + 역전파 + 경사하강법
  • 엄청난 연산, 끝나면 다이얼 고정
  • 우리가 할 일은 별로 없다
Inference · 추론

고정된 다이얼로 답 만들기

  • 순전파만, 가중치 업데이트 없음
  • ChatGPT와의 대화는 전부 추론
  • 우리가 맨날 한다

모델이 내 말을 "기억"하는 듯 보이는 이유: 대화 전체가 매번 다시 입력으로 들어가기 때문

10프리필과 디코딩

추론의 두 박자

① 프리필 (prefill)

프롬프트 전체를 병렬로 통과
계산량이 많아 연산력이 속도를 좌우

② 디코딩 (decoding)

한 토큰씩 순차 생성 · 행렬-벡터 곱 위주
메모리 대역폭이 속도를 좌우 (memory-bound)

실전 팁

캐시 히트를 내는 네 가지 습관

안 바뀌는 건 앞에

tools → system → messages. 앞이 바뀌면 뒤가 모두 무효

바이트 단위까지 동일

맨 앞 "현재 시각" 금지. 툴 순서·JSON 키 순서 변화도 캐시를 깬다

최소 길이 넘기기

너무 짧으면 cache_control을 붙여도 조용히 캐싱 안 됨

TTL 안에 재사용

노트엔 유통기한이 있다. 툴은 지우지 말고 tool_choice:"none"

안 바뀌는 건 앞에 두고, 한 글자도 건드리지 마세요.
