03의미 공간

Embedding: 단어에 좌표를 주기

Token 번호에는 의미가 없습니다. 그래서 각 Token을 수백~수천 개 숫자의 Vector로 바꿉니다. Transformer 원 논문은 512개, 현재 가장 큰 open-weight 모델 Kimi K3는 7,168개.

비유거대한 지도. 의미가 비슷한 단어끼리 가까이 모여 있습니다.
비유의 한계실제 지도는 수천 차원이고, 축에 사람이 붙일 수 있는 이름도 없습니다. 좌표도 사람이 정하지 않고 학습 과정에서 저절로 만들어집니다.

word2vec (2013): king − man + woman을 계산하면 queen에 가장 가까운 Vector가 나옵니다.

07구조

Decoder의 규칙: 앞만 보기

Attention(Token끼리 정보 교환) → Feed-forward(각자 소화) Block을 층층이 쌓은 것이 Layer. 아래층은 단순한 pattern을, 위층으로 갈수록 더 추상적인 관계를 다룬다고 흔히 설명합니다.

원래 Transformer는 Encoder(원문 읽기) + Decoder(번역문 쓰기)로 된 번역기였습니다. GPT 계열은 Decoder만 쌓았고, ChatGPT·Claude·Llama 등 대화형 LLM 대부분이 Decoder-only입니다.

각 Token은 자기보다 앞에 있는 Token만 볼 수 있습니다 (Masking). 다음 Token을 맞히는 모델이 정답을 미리 보면 안 되니까요.

비유Assembly line. 원재료(Embedding)가 수십 개 공정(Layer)을 거쳐 확률표라는 완제품이 됩니다.

TIP 1

고정은 앞, 변동은 뒤

System Prompt·Tool 정의·참고 문서를 맨 앞에, 사용자 질문은 맨 뒤에. Anthropic은 tools → system → messages 순서로 Prefix를 만들고, 앞 단계가 바뀌면 그 뒤가 모두 무효가 됩니다.

TIP 2

Byte 단위까지 똑같이

맨 앞의 현재 시각은 Cache를 한 장도 못 쓰게 만듭니다. OpenAI는 Timestamp를 끝으로 옮기라고 하고, Anthropic은 Timestamp 블록에 Cache 지점을 두면 쓰기 비용만 내고 읽기는 한 번도 못 한다고 경고합니다. Tool 순서·Schema, JSON (JavaScript Object Notation) key 순서 변경도 주의. Tool을 끄려면 정의를 지우지 말고 tool_choice: "none".

TIP 3

최소 길이 넘기기

OpenAI 1,024 · Anthropic 512~4,096 · Gemini 2,048~4,096 Token 미만은 Cache 안 됨. Anthropic은 짧으면 cache_control을 붙여도 오류 없이 그냥 Cache 없이 처리합니다.

TIP 4

TTL (Time To Live) 안에 다시 쓰기

Anthropic: 기본 5분, 쓸 때마다 무료 갱신 (1시간 옵션은 추가 요금). OpenAI: API는 최대 12시간, Codex login 시 영구 보관. Gemini: 비슷한 Prefix의 Request를 짧은 시간 안에 보내라고만 권장.
